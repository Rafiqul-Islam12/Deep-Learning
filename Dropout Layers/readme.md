# ***Dropout Layer***

***Dropout Layer হলো Neural Network-এর একটি **Regularization Technique**, যা Training-এর সময় Random ভাবে কিছু Neuron সাময়িকভাবে Disable (Drop) করে দেয়। এর ফলে Model কোনো নির্দিষ্ট Neuron-এর উপর অতিরিক্ত নির্ভর করে না, **Co-adaptation কমে** এবং **Overfitting প্রতিরোধ হয়**। Dropout-এর একটি Rate (যেমন 0.5) নির্ধারণ করা হয়, যা কত শতাংশ Neuron Drop হবে তা নির্দেশ করে। Training-এর সময় Dropout সক্রিয় থাকে, কিন্তু **Testing-এর সময় সব Neuron ব্যবহার করা হয়**, ফলে Model নতুন (Unseen) Data-তে আরও ভালো **Generalization** প্রদান করে।***
